# Dokumentasi Proyek

Struktur folder ini mengorganisir dokumen proyek berdasarkan area:

```
docs/
├── README.md              ← file ini
├── architecture/          ← desain sistem, arsitektur modul
├── research/              ← materials untuk thesis (judul, referensi, justifikasi)
├── roadmap/              ← tracking pekerjaan yang belum selesai
└── article/              ← (dihapus — konten dipindah ke research/)
```
